Masked superstrings

Algorithms and data structures for k-mer sets

ACGtAca

Masked superstrings represent sets of k-mers using a string together with a mask that identifies the starting positions of selected k-mers. They provide a framework for compact representations, efficient indexing and operations on genomic data.

Example (k = 3). ACGtAca represents {ACG, CGT, GTA, ACA}, using uppercase letters to mark selected starting positions.
