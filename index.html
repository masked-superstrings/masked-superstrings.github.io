01 / The project

From incomplete patterns to rigorous solutions.

The shortest common superstring problem asks for the smallest string containing a collection of strings as substrings. The masked variant adds uncertainty: some positions are unknown, and a solution must account for every valid completion.

This project brings together theory and computation to understand that uncertainty—developing reproducible methods, testing conjectures, and sharing results with the research community.
