# masked-superstrings.github.io

Source of the [Masked superstrings](https://masked-superstrings.github.io) website: research and software on masked superstrings, a framework for compact representations, indexing, and operations on *k*-mer sets.

The site is a single static page, [`index.html`](index.html), served by GitHub Pages.

The figures in the About section are plain HTML/SVG. Their data-driven parts, between the comments `<!-- gen:NAME -->` and `<!-- /gen:NAME -->`, are generated from the tables of the papers; do not edit them by hand.

The social preview [`og-image.png`](og-image.png) is rendered from [`og-image.svg`](og-image.svg) by `rsvg-convert -w 1200 og-image.svg -o og-image.png`.
